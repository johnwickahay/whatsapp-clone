# WhatsApp Hooks - AGENTS.md

Custom hooks specifically for the WhatsApp clone's logic.

## Hooks
- `use-chat-data.ts`: Fetches and manages metadata for a specific chat.
- `use-chat-search.ts`: Logic for searching within a chat.
- `use-chat-selection.ts`: Handles message selection and bulk actions.
- `use-statuses.ts`: Manages status/stories data and state.
