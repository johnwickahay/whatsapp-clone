# Components Directory - AGENTS.md

General UI components used throughout the application.

## Subdirectories
- `ui/`: Generic, reusable UI components (buttons, inputs, etc.), many based on shadcn/ui.
- `icons/`: Custom SVG icon components.
- `tutorial/`: Components used for instructional purposes or initial setup.
- `whatsapp/`: Core business logic and UI for the WhatsApp clone.
