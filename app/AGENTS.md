# App Directory - AGENTS.md

This directory contains the Next.js App Router routes, including layouts, pages, and API routes.

## Key Files
- `layout.tsx`: Root layout with font and theme providers.
- `page.tsx`: Entry point that renders the `WhatsAppHomeShell`.
- `globals.css`: Tailwind 4 styles and CSS variables.

## Subdirectories
- `api/`: Backend API routes.
- `auth/`: Authentication flow pages (login, sign-up, etc.).
- `protected/`: Routes that require an authenticated session.
